Purpose

My MSc Data Analytics dissertation (Oxford Brookes University, 2024): can the sentiment of financial news headlines tell us anything about short-term stock price movements?

The project compares two sentiment models on a labelled dataset, then applies the better-balanced one to live headlines for Apple, with Amazon, Alphabet and Walmart as cross-sector comparisons.

Tools

Python | pandas | VADER | TextBlob | yfinance | GitHub Actions | Jupyter

Summary

I built an automated pipeline that scraped daily news headlines from Finviz on a schedule, scored each headline's sentiment, and joined the results to historical prices from Yahoo Finance.

Before trusting either model, I benchmarked VADER and TextBlob against Kaggle's labelled financial news dataset (4,846 headlines), then used the chosen model for an Apple case study covering 10 to 22 September 2024.

Process

  • Wrote a Python scraper for Finviz news tables and scheduled it to run daily with GitHub Actions, saving each run as a timestamped CSV.
  • Merged, cleaned and de-duplicated the scraped files with pandas.
  • Scored every headline with VADER and TextBlob and bucketed scores into positive, neutral and negative.
  • Evaluated both models against the labelled Kaggle dataset using accuracy, per-class F1 and confusion matrices.
  • Pulled daily opening and closing prices with yfinance and compared Apple's daily mean sentiment with its price movement.

Key Insights

  • TextBlob scored higher overall (58.5% vs 55.0%) but only because it labels most headlines neutral. Its negative-class F1 was just 0.13.
  • VADER was far more balanced (negative F1 0.32, positive F1 0.51), so I chose it as the primary model. Headline accuracy alone would have picked the wrong one.
  • Apple's sentiment and price moved together from 10 to 19 September, both rising and then falling.
  • The link broke at the iPhone 16 launch on 20 September 2024: the price rebounded sharply while headline sentiment stayed negative.
  • Sentiment is a useful short-term signal but not a standalone predictor. General-purpose lexicons also struggle with financial language, pointing to FinBERT as the next step.

Outcome

A reproducible Python pipeline, from automated data collection to model evaluation and a real-world case study, with every figure regenerable from the notebook in the repository.
